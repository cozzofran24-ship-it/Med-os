Dati e sicurezza

Il backup esporta materie, attività, argomenti e note in un file JSON. Conservalo nell'app File in un luogo sicuro.

L'importazione sostituisce i dati correnti dopo conferma. Non include PDF esterni.

Diagnostica

Il test scrive e legge un dato temporaneo. Non certifica da solo la persistenza dopo la chiusura.

Backup completo (dati + PDF)

Questo backup ZIP comprende attività, materie, esami, argomenti i documenti PDF offline e i collegamenti Drive. È diverso dal backup JSON di base.

Installazione

Per usare MED-OS come vera PWA offline occorre aprire la cartella tramite un'origine HTTPS, aggiungerla alla schermata Home e verificare l'installazione del Service Worker.

Aprire index.html dall'app File serve solo per un'anteprima: iOS può bloccare l'archiviazione o JavaScript.
